MyFootyLife / Soccer Career Simulator
Version: v1.0003

CHANGE IN v1.0003 — INTERACTIVE SITUATIONS
- Added an interactive Situation screen that can appear during a career season.
- Each situation gives exactly 3 choices: Easy, Medium, Hard.
- Each choice displays one exact Success percentage and one exact Failure percentage.
- Success + Failure percentages always total 100%.
- Removed the old percentage ranges.
- Removed the “Potential Outcomes Affect” section from the situation UI.
- Outcomes can change Coach Trust, Team Trust, Reputation, Overall, Appearances, Goals and Assists.
- Positive results provide the listed reward; negative results apply a reduced negative version of the same type of effect.
- Successful choices do not automatically add a fatigue penalty.
- The exact odds are visible before the player chooses.
